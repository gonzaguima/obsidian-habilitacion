# Dudas operacionales abiertas

Usar esta nota sólo para datos que no conviene suponer en operación. Cada fila debe cerrarse con una fuente vigente o confirmación del OJTI; un resumen de estudio no basta para cerrar un dato local.

| Tema | Duda concreta | Riesgo si se asume | Fuente / OJTI | Respuesta confirmada | Fecha | Estado |
|---|---|---|---|---|---|---|
| PEA | Cartilla y contactos actualmente usados en TWR | Notificación incompleta o por medio incorrecto |  |  |  | ⬜ |
| PEA | Alcance de la coordinación vehicular del PMM en Alerta 3 | Confundir mando/área de movimientos |  |  |  | ⬜ |
| CNS | Respaldo real para cada falla de SDC/SDD/radio/luces | Continuar con un medio no autorizado |  |  |  | ⬜ |
| Fajas | Simbología local y casos especiales | Imagen operacional incompleta |  |  |  | ⬜ |
| Coordinación | Medio/momento de coordinación de cada CAO frecuente | Transferencia o aviso tardío |  |  |  | ⬜ |
| Radioayudas | Dónde se consulta el estado y quién comunica el restablecimiento | Usar una ayuda no disponible |  |  |  | ⬜ |

## Regla de cierre

- **Verde:** fuente vigente identificada y entendida.
- **Amarillo:** respuesta recibida, pendiente de ubicar fuente o practicarla.
- **Rojo:** dato crítico aún sin confirmar; llevarlo al briefing antes de depender de él.

Al cerrar una duda, trasladar la respuesta útil al resumen o tarjeta correspondiente y conservar aquí el enlace a la fuente.
