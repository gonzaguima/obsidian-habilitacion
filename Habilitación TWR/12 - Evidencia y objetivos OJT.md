# Evidencia y objetivos OJT

Las horas muestran exposición; la evidencia muestra progreso. Registrar sólo hechos observables, no etiquetas generales como “me fue bien”.

## Objetivo de la próxima guardia

> Objetivo único:  
> Señal que voy a buscar:  
> Acción que practicaré:  
> Cómo sabré que funcionó:

## Revisión cada tres guardias

1. ¿Qué conducta se repitió bien con evidencia?
2. ¿Qué corrección se repitió o aparece bajo carga?
3. ¿Qué fuente, tarjeta o escenario hace falta repasar?
4. Elegir **un** objetivo observable para las próximas tres guardias.
