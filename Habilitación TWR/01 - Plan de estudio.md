# Plan de estudio

Volver a [[00 - Inicio]].

## Principio de trabajo

No intentar memorizar todo de corrido. Para cada tema, poder responder:

1. ¿Qué tengo que detectar?
2. ¿Qué decisión debo tomar?
3. ¿Qué procedimiento o separación corresponde?
4. ¿Con quién debo coordinar?
5. ¿Qué información debo transmitir y con qué fraseología?
6. ¿Cómo verifico que la acción tuvo el resultado esperado?

## Preparación para la semana previa

### Día 1 — Entorno de trabajo

- [ ] Estudiar briefing, relevo y debriefing.
- [ ] Identificar puestos y distribución de responsabilidades.
- [ ] Enumerar fuentes que deben revisarse al asumir posición.
- [ ] Reconocer equipos CNS, SDC, SDD y medios de reserva.
- [ ] Preparar [[Plantillas/Jornada OJT - Plantilla]].

### Día 2 — Aeródromo y espacio aéreo

- [x] Dibujar de memoria pistas, calles de rodaje y plataformas.
- [x] Marcar puntos críticos y posiciones de estacionamiento especiales.
- [x] Dibujar ATZ, CTR y TMA con límites y clasificación.
- [x] Repasar circuitos civiles, militares y de helicópteros.
- [x] Ubicar obstáculos y referencias visuales principales.

### Día 3 — Procedimientos y coordinación

- [ ] Identificar dependencias y sectores adyacentes.
- [ ] Repasar cartas de acuerdo y procedimientos interservicios.
- [ ] Preparar una tabla: evento → coordinación → momento → medio → fraseología.
- [ ] Repasar transferencias, autorizaciones e información de tránsito.
- [ ] Identificar procedimientos ante fallas de comunicaciones.

### Día 4 — Meteorología y operación

- [ ] Interpretar METAR, SPECI, TAF y SIGMET reales.
- [ ] Repasar techo, visibilidad, viento y cortante de viento.
- [ ] Diferenciar QNH, QFE y QNE.
- [ ] Relacionar fenómenos meteorológicos con pista, circuito y separaciones.
- [ ] Practicar cómo transmitir información meteorológica de forma concisa.

### Día 5 — Emergencias y contingencias

- [ ] Identificar fases de alerta y cadena de notificación.
- [ ] Repasar plan de emergencia del aeródromo.
- [ ] Analizar fallas de SDC, SDD, radioayudas, energía y luces.
- [ ] Practicar prioridades: reconocer, verificar, proteger, coordinar, asistir y vigilar.
- [ ] Preparar escenarios para comentar con el instructor.

### Día 6 — Competencias

- [ ] Leer [[04 - Competencias evaluadas]].
- [ ] Anotar un comportamiento observable para cada competencia.
- [ ] Identificar dos fortalezas y dos riesgos personales.
- [ ] Practicar verbalización anticipada de conflictos y amenazas.
- [ ] Repasar mecanismos para pedir ayuda y gestionar carga de trabajo.

### Día 7 — Simulación mental y repaso

- [ ] Realizar un relevo completo en voz alta.
- [ ] Simular una secuencia desde puesta en marcha hasta salida.
- [ ] Simular una llegada, aterrizaje y liberación de pista.
- [ ] Agregar meteorología adversa o una falla de equipo.
- [ ] Contestar [[Repaso/Preguntas de repaso]] sin mirar apuntes.
- [ ] Marcar dudas para el primer briefing con el OJTI.
