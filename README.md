# Habilitación TWR — OJT

Espacio personal de estudio y seguimiento para la habilitación de Control de Aeródromo (TWR) en el marco de entrenamiento en el puesto de trabajo (OJT), con foco en SULS.

Reúne el plan de estudio, apuntes por jornada, repasos operativos, ejercicios de fraseología y documentación de consulta. Las notas están pensadas para abrirse en [Obsidian](https://obsidian.md/), aunque también pueden leerse como archivos Markdown.

> [!warning]
> Este repositorio es material de apoyo para el estudio. No sustituye la documentación operacional vigente, las cartas de acuerdo, las publicaciones AIP, el MADOR ni las instrucciones del OJTI. Ante cualquier diferencia, prevalece siempre la fuente oficial vigente y la instrucción operacional aplicable.

## Inicio rápido

1. Abrir [00 - Inicio](Habilitaci%C3%B3n%20TWR/00%20-%20Inicio.md) como índice principal.
2. Revisar [01 - Plan de estudio](Habilitaci%C3%B3n%20TWR/01%20-%20Plan%20de%20estudio.md) para conocer el avance y los próximos bloques.
3. Usar [02 - Programa teórico](Habilitaci%C3%B3n%20TWR/02%20-%20Programa%20te%C3%B3rico.md) para estudiar por tema y registrar pendientes.
4. Consultar [03 - Primeros cuatro días OJT](Habilitaci%C3%B3n%20TWR/03%20-%20Primeros%20cuatro%20d%C3%ADas%20OJT.md) antes y después de cada jornada inicial.
5. Convertir correcciones y dudas en acciones mediante las notas de repaso, tarjetas y evidencia OJT.

## Forma de uso

- Mantener los enlaces `[[internos]]` para conservar la navegación entre notas en Obsidian.
- Registrar al finalizar cada jornada: situaciones observadas, correcciones del OJTI, evidencia y siguiente objetivo concreto.
- Marcar como completado solo el contenido realmente tratado; la aplicación en puesto debe seguir diferenciada de la lectura teórica.
- Anotar edición, fecha de vigencia y enmiendas al tomar datos de un documento de referencia.

## Documentación de referencia

Las carpetas [DOCUMENTOS](Habilitaci%C3%B3n%20TWR/DOCUMENTOS/) y [DOCUMENTOS DE CONSULTA](Habilitaci%C3%B3n%20TWR/DOCUMENTOS%20DE%20CONSULTA/) contienen manuales, AIP, procedimientos, cartas de acuerdo, formularios, estadísticas y otros materiales de consulta. Pueden quedar desactualizados: verificar siempre su vigencia antes de usarlos en la operación o en una evaluación.

## Alcance y confidencialidad

El contenido se organiza con fines de aprendizaje individual. No publicar, redistribuir ni usar documentación interna o de circulación restringida fuera de las autorizaciones aplicables. Evitar incorporar información operacional sensible, datos personales o registros que no estén autorizados para este repositorio.
